# SAC’ADOS — PIXEL KINGDOM DELUXE V3

## Ce qui change

V3 intègre 31 **illustrations pixel art individuelles** originales (sans texte intégré), ainsi que 8 icônes de disciplines, 5 icônes de catégories et 8 petites icônes d'interface. Tous les visuels de la V2.2, notamment le menu inférieur PNG détouré, restent présents.

Les illustrations sont des fichiers WebP (assets/apps/) et PNG transparents (assets/disciplines/, assets/categories/, assets/icons/) réellement séparés : les textes et les interactions restent en HTML. Une illustration peut être remplacée sans modifier le JavaScript ni changer les autres.

## Installation GitHub Pages

Décompresser l'archive. Dans GitHub Desktop, ouvrir le dossier du dépôt via **Repository > Show in Explorer** et copier **le contenu du dossier SACADOS-PIXEL-KINGDOM-V3** à la racine du dépôt : `index.html`, `css/`, `js/`, `assets/`. Ne pas déposer le dossier parent. Faire Commit puis Push Origin.

## Vérification / limitations

Le catalogue 31 applications, les trois liens renseignés dans le fichier d'origine, les classes, filtres, recherches, favoris, quêtes, découvertes, réglages et l'espace professeur sont préservés. Les autres URLs restent volontairement vides. Les sauvegardes locales sont maintenues sous la clé `sacados_v1`.

Cette V3 ajoute des *vignettes pixel art 16 bits cohérentes*, non des peintures haute définition : une future version pourra remplacer individuellement chaque vignette par des illustrations plus élaborées. La grande carte et ses textes intégrés n'ont pas été changés dans cette livraison, pour préserver la mise en page validée en V2.2.

**Conseil :** vérifier le nouveau rendu mobile et desktop après publication, et forcer le rechargement avec Ctrl+F5 si les nouveaux styles restent en cache.
