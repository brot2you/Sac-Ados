# Sac’Ados V5.2 — Éclat doré sur les icônes

Cette version garde exactement la V5.1 et ses images (carte, menus, catégories, jaquettes, liens). Elle ajoute uniquement un effet visuel CSS sur les cinq icônes des catégories : lumière or douce, reflets ponctuels et scintillements sur les cartes dans Mes quêtes, et halos discrets dans le Sac et les filtres des disciplines.

Aucun fichier image ne change. Aucun son ni comportement JavaScript ne change. Le mode calme et la préférence système « réduire les animations » désactivent l’animation.

## Mise à jour légère depuis V5.1
Copier à la racine du dépôt les deux fichiers `index.html` et `css/category-gold-v5.2.css` depuis le ZIP de mise à jour, sans supprimer les autres dossiers. Ensuite : GitHub Desktop → Commit to main → Push origin → recharger la page avec Ctrl+F5.
