SAC’ADOS — Pixel Kingdom Deluxe V4.7
Correctif visuel : émojis des 8 disciplines + nouvelle illustration BOOST.

Cette version conserve l’accueil carte seule, le menu RPG centré, les fonctionnalités et les sons de la V4.6.

CHANGEMENTS
- 8 visuels de disciplines (anglais, français, maths, histoire, géographie, musique, arts plastiques, toutes matières), façon émoji brillant, sans cadres ni textes intégrés.
- Boost : nouvelle fusée illustrée, carré 640 × 640 pixels.
- Cache : l’application demande les nouvelles images avec un identifiant de version, pour éviter d’afficher les anciennes icônes.

INSTALLATION AVEC GITHUB DESKTOP
1. Décompresser l’archive « MISE-A-JOUR » dans un dossier temporaire.
2. Dans GitHub Desktop : Repository > Show in Explorer.
3. Copier tout le contenu décompressé dans le dossier racine de Sac’Ados. Accepter le remplacement des fichiers, sans supprimer les autres.
4. Dans GitHub Desktop : Commit to main puis Push origin.
5. Actualiser le site publié (Ctrl+F5).

Les données personnelles (classe, favoris et liens personnalisés) demeurent enregistrées localement dans le navigateur : aucun reset n’est réalisé.
