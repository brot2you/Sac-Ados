# SAC’ADOS V5.1 — 5 nouvelles icônes de catégories

Basé sur la V5. Les cinq catégories sont désormais représentées par les nouvelles illustrations, recadrées individuellement et placées dans des images carrées 512 × 512 px avec fond transparent et marges de sécurité.

Elles apparaissent dans l’inventaire, les sections des applications, les fiches et dans « Mes quêtes » comme raccourcis vers les catégories du sac.

La carte, les liens des applications, le menu inférieur, la sauvegarde locale et les effets sonores restent inchangés.

Pour la mise à jour depuis V5, copier le contenu du ZIP correctif à la racine du dépôt, en conservant l’arborescence js/ et assets/. Puis faire Commit et Push dans GitHub Desktop. Une fois GitHub Pages publié, faire Ctrl+F5.
